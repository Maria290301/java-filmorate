# java-filmorate
Filmorate — бэкенд-сервис для фильмов и социальных рекомендаций
Filmorate — это REST-приложение на Spring Boot, которое я разработала для хранения информации о фильмах, пользователях и их взаимодействиях. Проект реализует основные возможности социальной платформы: лайки, добавление в друзья, расчёт популярности фильмов.

В рамках 11 спринта я переработала архитектуру приложения, разделив ответственность между контроллерами, сервисами и хранилищами, внедрила бизнес-логику и обеспечила соответствие спецификации REST.

Реализованный функционал
Архитектура
Логика разделена по слоям:

Controller — отвечает за маршрутизацию и приём HTTP-запросов;

Service — содержит бизнес-логику;

Storage — управляет хранилищем данных (в текущей версии — in-memory).

Используются интерфейсы FilmStorage и UserStorage, что обеспечивает гибкость при расширении проекта.

Все зависимости внедряются через конструкторы с использованием аннотаций @Autowired, @Component, @Service.

Бизнес-логика
Пользователи
Добавление, обновление, получение пользователей;

Добавление в друзья и удаление из списка друзей;

Получение списка всех друзей;

Получение списка общих друзей с другим пользователем.

Фильмы
Добавление, обновление, получение фильмов;

Возможность лайкать и удалять лайк у фильма;

Получение списка самых популярных фильмов (по количеству лайков);

Один пользователь может поставить лайк одному фильму только один раз.

REST API
Примеры эндпоинтов:

Метод	URL	Описание
POST	/users	Добавление нового пользователя
PUT	/users	Обновление пользователя
GET	/users/{id}	Получение пользователя по ID
PUT	/users/{id}/friends/{friendId}	Добавление друга
DELETE	/users/{id}/friends/{friendId}	Удаление друга
GET	/users/{id}/friends	Получение списка друзей
GET	/users/{id}/friends/common/{otherId}	Общие друзья
POST	/films	Добавление фильма
PUT	/films	Обновление фильма
GET	/films/{id}	Получение фильма по ID
PUT	/films/{id}/like/{userId}	Пользователь ставит лайк фильму
DELETE	/films/{id}/like/{userId}	Пользователь удаляет лайк
GET	/films/popular?count={count}	Получение топ-N популярных фильмов

Валидация
Для Film:

Название не пустое;

Описание — не более 200 символов;

Дата релиза — не ранее 28.12.1895;

Продолжительность — положительное число.

Для User:

Email содержит @ и не пустой;

Логин не пустой и без пробелов;

Имя может быть пустым — в таком случае используется логин;

День рождения не в будущем.

Логирование
Логируются все изменения сущностей;

Добавлено логирование ошибок валидации и логических исключений;

Интегрирована библиотека Logbook:

Включён вывод запросов и ответов в формате JSON;

Уровень логирования: TRACE.

Пример настройки Logbook:

xml
Копировать
Редактировать
<dependency>
    <groupId>org.zalando</groupId>
    <artifactId>logbook-spring-boot-starter</artifactId>
    <version>3.7.2</version>
</dependency>
yaml
Копировать
Редактировать
logging.level.org.zalando.logbook: TRACE
Исключения и коды ответа
400 Bad Request — ошибка валидации;

404 Not Found — если объект не найден;

500 Internal Server Error — ошибка при обработке запроса.

Тестирование
API протестирован вручную через Postman (см. коллекцию postman.json);

Все граничные сценарии протестированы: ошибки валидации, повторные лайки, некорректные ID, пустые поля и т.д.
