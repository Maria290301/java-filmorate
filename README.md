# java-filmorate
Template repository for Filmorate project.

## Диаграмма
![diagram.png](src/main/resources/diagram.png)


Данная диаграмма иллюстрирует структуру базы данных для проекта Filmorate. Она включает в себя основные таблицы, такие как:
- **Users**: информации о пользователях.
- **Films**: информация о фильмах.
- **Likes**: данные о лайках пользователей.
- **Friendships**: данные о дружбе между пользователями.
- **Genres**: жанры фильмов.
- **Mpa**: рейтинги фильмов.

Filmorate — бэкенд-сервис для фильмов, рекомендаций и отзывов
Filmorate — это REST-приложение на Spring Boot, которое я разработала в рамках учебного курса. Основная идея — создать социальную платформу, где пользователи могут оценивать фильмы, оставлять отзывы, добавлять друзей и получать персональные рекомендации.

Проект прошёл через несколько этапов: от in-memory REST-сервиса до полноценного командного приложения с интеграцией базы данных, отзывами, лентой событий и расширенным поиском.

 Что реализовано
 Базовая функциональность
Работа с фильмами: добавление, обновление, получение по ID, лайки и рейтинг популярности.

Работа с пользователями: регистрация, обновление, добавление в друзья, получение общих друзей.

Валидация входных данных через javax.validation.

Временное хранение данных в памяти (HashMap) на первых этапах.

 Расширение логики
Лайки фильмов: пользователь может лайкать фильмы, один лайк от одного пользователя.

Популярные фильмы: формирование рейтинга по количеству лайков.

Дружба: одностороннее добавление и удаление, список друзей, общие друзья.

 Работа с БД и переход на JDBC
Подключила H2 Database с schema.sql.

Перевела приложение на DAO-архитектуру через JdbcTemplate.

Создала UserDbStorage и FilmDbStorage для работы с БД.

Добавила поддержку жанров (genres) и рейтингов (mpa) для фильмов.

 Новые сущности и API
GET /genres, GET /mpa — справочники жанров и рейтингов.

GET /films/popular?count=N — топ-N популярных фильмов.

Поддержка удаления пользователей и фильмов.

Корректная обработка ошибок: 400, 404, 500.

 Командная разработка и новые фичи
 Отзывы (/reviews)
Сущность Review: создание, обновление, удаление, получение.

Возможность ставить лайки и дизлайки отзывам.

Отображение отзывов к каждому фильму.

 Лента событий (/feed)
Сущность Event: лог действий пользователя.

Эндпоинт GET /users/{id}/feed: отображение событий (добавление в друзья, лайки, отзывы).

 Расширенный функционал
Поиск фильмов по названию и описанию.

Фильмы по режиссёрам.

Общие фильмы между пользователями.

Популярные фильмы по жанру и году.

Персональные рекомендации на основе лайков.

 Архитектура проекта
Многоуровневая архитектура: контроллеры → сервисы → DAO;

Интерфейсы хранилищ: FilmStorage, UserStorage, ReviewStorage и др.;

Аннотации Spring: @Service, @Repository, @Component, @Qualifier;

DTO и мапперы: для разделения бизнес-логики и API.
